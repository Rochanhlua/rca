# Changelog

## Unreleased

- **Implemented:** §12 Phase 7 dev tool #10 — `rcac debugger <file.rca>` runs the file with an interactive pause loop. Pauses at the first instruction by default (no breakpoints), then reads commands from stdin: `:c/:continue`, `:s/:step`, `:n/:next`, `:b/:break <line>`, `:d/:delete <line>`, `:l/:locals`, `:st/:stack`, `:h/:help`, `:q/:quit`. VM infrastructure: `Debugger` struct, `Vm::with_debugger`, per-instruction pause check; zero overhead when no debugger is attached. No imports yet (documented). New `tests/debugger.rs` (7 tests).
- **Implemented:** §12 Phase 7 dev tool #11 — `rcac coverage <file.rca>` runs the file with `VmStats` enabled and reports source lines, code lines (excluding blanks and `#` comments), covered/missed counts, coverage percentage, and the list of missed lines (up to 40). Reuses the VM foundation from #159; no VM change required. Also fixes #159's missed `profile` entry in the `commands` array. No imports yet (documented). New `tests/coverage.rs` (4 tests).
- **Implemented:** §12 Phase 7 dev tool #12 (first slice) + dev tool #10/#11 foundation — VM instrumentation (`VmStats`: instruction count, line hits, per-function call count and wall-clock ns) collected only via `Vm::with_stats`; off by default, zero overhead otherwise. New `rcac profile <file.rca>` runs the file with stats and prints instructions, top-10 functions by time, and top-10 hottest lines. No imports yet (documented). New `tests/profile.rs` (4 tests).
- **Implemented:** §12 Phase 7 dev tool #9 — `rcac completion <bash|zsh|fish>` prints a shell completion script to stdout (commands, pkg actions, file completion). Scripts live in `assets/completion/` and are embedded with `include_str!`. New `tests/completion.rs` (5 tests).
- **Implemented:** §12 Phase 7 dev tool #8 — `rcac watch <file.rca>` polls mtime every 500 ms and re-runs the file (`rcac run`) on change; initial run happens immediately. Ctrl+C to stop. New `tests/watch.rs` (2 tests, both use a short child timeout).
- **Implemented:** §12 Phase 7 dev tool #7 — `rcac bench <file.rca> [N]` runs a file N times (default 5) after a warmup, reporting min / avg / max wall-clock ms plus all per-iteration times. Runs each iteration as a fresh subprocess (`rcac run`), so startup cost is included. New `tests/bench.rs`.
- **Implemented:** §12 Phase 7 dev tool #6 — `rcac doc <file.rca>` prints Markdown API docs to stdout for `pub fn` / `pub struct` / `pub enum`. Doc comments are the `#` lines immediately above an item. Signatures rendered from the AST. New `src/compiler/doc/mod.rs`, `tests/doc.rs` (5 tests). HTML output and cross-references not implemented.
- **Implemented:** §12 Phase 7 dev tool #5 (minimal) — `rcac lsp` JSON-RPC 2.0 server over stdio. Handles `initialize`, `initialized`, `shutdown`, `exit`; notifications `textDocument/didOpen` and `didChange` trigger parser/checker diagnostics published via `textDocument/publishDiagnostics`. Uses the crate's existing `json` module (no `serde_json`). New `src/compiler/lsp/mod.rs`, `tests/lsp.rs`. Hover, completion, go-to-def, formatting not yet implemented.
- **Implemented:** §12 Phase 7 dev tool #4 — `rcac repl` interactive loop: each line is parsed, checked, lowered, and run on a fresh VM. `:quit`/`:q` exit; `:help` prints commands. State is not preserved between lines yet (documented). New `src/compiler/repl/mod.rs`, `tests/repl.rs` (5 tests).
- **Implemented:** §12 Phase 7 dev tool #3 — `rcac fmt <file.rca>` prints canonical formatting (4-space indent, single spaces around binary operators, no space before `:` or closing brackets, comments preserved verbatim). Token-based, idempotent. New `src/compiler/fmt/mod.rs`, `tests/fmt.rs` (4 tests). Does not write in place yet; prints to stdout.
